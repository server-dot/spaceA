- [ ] 真正加分的是**機制**再接「所以怎麼做」：氨偏鹼所以弱酸中和、季銨鹽只殺菌管不到空氣裡的味道、酵素要靜置、五種標章各是測什麼；機制只寫確定的化學／常識。每段至少一個做過功課才知道的細節。
- [ ] 風格類指示先改一段給使用者看，確認再鋪全篇。

### FAQ

- [ ] 答案每題給一個明確判斷，不是「適合…也適合…同樣合適」的空話。
- [ ] 客戶資料夾的飼主問題補 2～3 題（見第 2 節）。

### 總結

- [ ] 寫成一段說明文：這類東西的差別在哪 → 選購時該確認什麼、為什麼 → 下訂前注意事項 → 「若想進一步比較，可參考各品牌公開的…資訊」並列三家（客戶其一）掛連結，不能只點客戶。

### 全文通用

- [ ] **所有 h2／h3 逐一唸出聲**：h2 是一句短句（10～16 字、不加問號、不接「先看…」「怎麼選」尾巴），h3 是完整短片語（有主詞有動詞、中間沒逗號）；取捨章 h3 例外見上。有冒號、兩個以上逗號、「問句？＋斷句」、結尾「不是…」的一律重寫。❌「日月潭、九族、埔里：一條路串起來，一天剛好」→ ⭕「日月潭、九族、埔里一天可以排在一起」；❌「穩定器和三腳架怎麼挑，不是兩個都要買」→ ⭕「穩定器和三腳架先挑一個就好」。
- [ ] **`<strong>` 包判斷句**，不能只包關鍵字或價格。❌`<strong>新店飯店</strong>房價 <strong>NT$1,200 到 3,500</strong>` → ⭕`<strong>新店飯店的房價多在 NT$1,200 到 3,500，碧潭湖景房會比大坪林貴一截</strong>`。前言、各章、總結各挑一兩句；n8n 前言／總結節點會強制關鍵字加粗，校稿時拿掉單獨的關鍵字粗體。
- [ ] 不寫「看＋品牌」：❌「預算有限可以看大醫生技」→ 交替用「選」「可以考慮」「適合」「不妨試試」，或直接寫那款的事實（「預算有限的人，大醫生技一天不到 NT$30」）；一句裡連用四個「選」一樣單調。寫完 grep `看(品牌名…)`。
- [ ] 點評、FAQ、總結不出現「這篇」；價位寫「在 OO 中屬於中高價位」（❌「介於這篇的中高價位」）。段落開頭不放先講一遍的泛用判斷句（❌「選常溫最省事」），直接講事實。
- [ ] 「官網寫／官網標示／官網宣稱」**全文掃**，只有這幾類留出處：①價格欄位 ②「官網未標示」的資料缺漏 ③使用禁忌與可否用在身上 ④效能與檢驗宣稱（抗菌、消臭、防黴）⑤查證出處（「查了十家官網」「以品牌官網為準」）、讀者該自己去查的（檢驗報告、法規審查狀態、成分來源）。其他直接寫事實。
- [ ] 沒有「未見／未發現／查無…獲獎／認證／紀錄」「未標明對應哪一款」「跟品牌其他產品線不是同一條」「官網未列獲獎」這類查核備註。
- [ ] 沒有負面新聞或內部研究備註（命案報導、行政爭議、「房間數描述不一致」）。
- [ ] 沒有關鍵字硬塞（❌「新店住宿與新北新店飯店推薦可依使用場景取捨」）。
- [ ] 錨文字有資訊（不要「了解更多」「點此」），外連補 `target="_blank" rel="noopener"`。

## 4. 卡片與小編點評

### 卡片欄位

- [ ] 「官方資訊」是條列、地址可點開地圖、官網／email／電話有連結；連首頁寫「官方網站」，連到某一款才寫「官方產品頁」；`href` 沒夾到換行或第二個網址。

- [ ] 卡片欄位裡不寫「官網寫／官網標示」（欄位名稱已經說了出處），例外只有效能宣稱與使用禁忌。

- [ ] B2B 殘留措辭：「合作體驗」「續約意願」「再次委派」「專案交付」改成消費者語氣（「入住體驗：」「回訪意願：」）。
- [ ] 破折號（—）一律不用，官方資訊、回購那行最常夾帶。

### 小編點評（我自己寫完直接進稿，整篇推 WP 前仍要等使用者說可以）

- [ ] 寫這款的**特色**與**消費者要權衡什麼**，不是把規格、包數、每單位換算再唸一次。
- [ ] 每個規格後面都接「這對讀者有什麼用」：專業名詞翻白話（500 Da → 切得很細、比較好吸收）；提到成分就講它好在哪（蜂王乳 → 有蛋白質、胺基酸、B 群，營養更完整）。
- [ ] 優勢要是產品本身的，直接點名（DV「同時兼具高劑量與好吸收」）；不靠周邊理由撐（❌「印在包裝上、不用再去查」「很多人會另外買」）。
- [ ] 結尾給具體做法，不給評價形容詞：⭕「可以順便喝一包」「可以選這款」；❌ 很順手、最省事、花這個錢有它的道理、心裡有底、排進每天的流程。
- [ ] 用字平實：產品不當主詞做人的動作（「它建議」拿掉；「它很划算」可以）；陳述事實不寫成體驗（「一包就喝到」→「一包就有」）。
- [ ] 價格、數字只在它就是推薦理由時才寫（天地合補 NT$399 好入手；m2 的 6,000mg 不是賣點就不寫）。
- [ ] 注意事項或小缺點可以加，放最後一句（台鹽「有蝦蟹過敏的人要避開」）。
- [ ] 句子走向：這款有什麼 → 對你有什麼好處 → 必要時補誰適合／怎麼做／注意事項。範本：「DV 一包有 12,000mg 膠原，分子量只有 284 Da，切得非常細，同時兼具高劑量與好吸收。」
- [ ] 要「文章敘述筆法」不是規格條列：先給背景或定位（市面上大多膠囊，這款做成飲品），再講特點，用「所以、不過、也正因為」串起來（1471）。Humanizer-zh 只修字面，不能拿它代替重寫。
- [ ] **只談這一款，不跟別的品牌比**：❌「十款裡最便宜」「僅次於畬室」「跟明治差不多」→ ⭕「在巧克力禮盒中屬於中高價位」（1622）。
- [ ] **完整句子**，第一句就講事實：❌「帶小朋友放電的好去處：全票 300、有沙坑、有滑梯」（冒號套規格）→ ⭕「全票 300 元，園區裡的沙坑和滑梯能讓小朋友耗掉一個下午。」❌「唱到半夜也不用管隔壁」（殘句）→ ⭕「唱歌唱到半夜也不怕被檢舉」。
- [ ] **十則句型每則都換**，開頭與收尾都不能重複（❌ 817 十則有九則「想／怕／第一次…的人，某某這款＋規格」）。生成器 `跨品牌點評審稿` 只擋結尾的「適合…的人」，模型會搬到開頭；要改那條規則先問。
- [ ] 不要「品牌名＋以…為主軸」開頭、不要「適合…的人」收尾；禁用 CP值、性價比、舒適、有質感、溫馨、貼心。
- [ ] 不要空泛社交判斷（❌「送不熟的客戶或長輩，對方多半認得這個牌子」「重點是一拿出來就看得出是禮物」）。
- [ ] 不要把讀者寫成被坑（❌「你買的其實是那些配角」→ ⭕「你買的其實涵蓋了許多其他的保養品」）；不要比喻腔（❌「沒有靠甜味劑撐」「賣的是乾淨兩個字」「只丟一支湯匙給你」「但這樣一盒只撐 15 天」）。
- [ ] 不能寫得像我們用過；第一人稱只放真的做過的事（把價格攤開算、讀完十家官網）。
- [ ] 改了某段就重讀一次改過的句子，確認沒換成另一種 AI 腔。

## 政策：揭露、圖片版權、不連積木

- [ ] **揭露**：只寫「spaceA 唯一對外販售的是標示為『廣告』的版位，其他都不販售」，只放推薦標準頁 #disclosure 與聯絡表單選廣告合作時的提示兩處；不逐項列「不接業配、不賣排名」，不寫「文中不含業配」「聯盟連結」，不加合作夥伴標籤或 `rel="sponsored"`。現行揭露句在 `src/lib/i18n.ts` 的 `disclosure`。這件事不要再主動重提。
- [ ] **客戶排名單第一**是既定做法，不調排序。
- [ ] **圖片版權**：官網形象照、店面、房型、商品圖直接用，不加「圖片來源」圖說，對方要求下架就先換圖再回，不爭。**絕對不用**：術前術後對比照、有浮水印或明顯攝影師作品的圖、其他部落客拍的照片。文字意見用自己的話重講、數字標出處、不逐字抄。
- [ ] **不連積木**：Organization／author JSON-LD 的 `sameAs` 不填 stack.com.tw（`ORG_SAME_AS` 留空），任何 SEO／GEO 加深、作者頁、外部提及都不主動把 spaceA 連到積木，要連先問；頁尾營運公司名是法規揭露，維持原樣。

- [ ] **SEO／GEO 基本盤**：sitemap、TKD、llms.txt、schema、FAQ 每頁都是必備；AI 爬蟲要真的進得來（GPTBot／ClaudeBot／PerplexityBot UA 各打一次文章頁，Cloudflare 擋了會回 403）；不存在的頁要回真 404。
