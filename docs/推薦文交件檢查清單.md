# 推薦文交件檢查清單

StackTool 的推薦文生成器（`推薦文-3-完整生成`）跑完之後，文章會**直接發布**到 WordPress（UI 上寫「草稿」是騙人的，實際 status 是 publish）。這份清單是生成後的健檢流程，逐項確認再交件。

範本：[新店飯店怎麼選？2026 精選 8 家住宿推薦](https://spacea.com.tw/travel/xindian-hotels-guide)（post 224，2026-09-10 校過的版本）

拿文章原始 HTML 的方式（`context=edit` 才拿得到未經 wpautop 的 `content.raw`，改內容一律用 raw）：

```bash
set -a && . .env.local && set +a
curl -s -u "$WORDPRESS_APP_USER:$WORDPRESS_APP_PASSWORD" \
  "https://recommend.dg166.com/wp-json/wp/v2/posts/<ID>?context=edit&_fields=content" -o /tmp/post.json
```

## 2. 內容與文案

先跑去 AI 味判讀（**每篇必跑，不是選配**）：把 `content.raw` 存成 `.html` 丟進一個資料夾，`cd /Users/kc/Desktop/qkangber && node scripts/check-ai-style.mjs <資料夾>`，腳本會把全文切段列出來，對照 `/Users/kc/Desktop/qkangber/docs/anti-ai-style.md` 逐段語意判讀（不是關鍵字比對），命中就重寫。推薦文常中的：

- [ ] 第一章「成效與成本差異／時間與上手難度／如何決定」＝ B2B 外包框架換皮，H3 全是冷標籤，整章重寫成這個主題自己的取捨（例：跟團還是自由行？先看你有幾天）
- [ ] 卡片的「實際使用感受」「回購傾向」兩行**保留**（2026-09-24 使用者決定：「留著吧，不奇怪啊」）。原本的規則是整行拿掉，已作廢。要改的是句子本身：研究備註口吻改人話，負評不要太深刻（「用後無感或認為行銷過度而不回購」這種整句重寫），破折號一樣不用。**醫療類（診所、醫美、牙科）例外，這兩行一律不放**——醫療廣告不得刊登病人見證與使用感受（380、497 已拿掉，2026-09-24 使用者定調「醫療就不動了，保守一點」）
- [ ] 前言**不要只放客戶一個連結**（2026-09-24 定調）：那是聯盟行銷文的長相。要放就按讀者需求點 2–3 家並各自連產品頁（客戶自然排最前面），連結一律連產品頁、不連品牌的部落格文章
- [ ] 卡片「官方資訊」欄不要放空話與殘句：「十年經營」「以電視廣告建立知名度」「結合專家合作擴大接受度」「年營業額突破億元」這類跟這款產品無關的品牌稿整條刪；**獎項不是這一款拿的就整條不要寫**，不要寫出來再解釋「這個獎其實是別款的」——那是替被推薦的品牌扣分，尤其客戶那張卡（2026-09-24）
- [ ] 同一個句型還有變體，一律不要：「未標明對應哪一款」「跟品牌其他產品線不是同一條」「官網未列獲獎」。這些是**查核備註**，不是文章內容——我查到的落差對讀者沒有資訊量。生成器的 `NEGATIVE_FINDING` 本來就在自動刪這種句子，手寫的時候也不要寫回去
- [ ] **卡片欄位裡不要寫「官網寫／官網標示／官網宣稱」**（2026-09-24 使用者：「這本來就是在官方資訊裡面了，不用特別講」）。整張卡就是品牌資料，欄位名稱已經說了出處，每條再標一次是贅字。例外只有兩個：效能宣稱（抗菌、消臭、防黴這種）與使用禁忌，留著出處
- [ ] 「官網寫／官網標示／官網宣稱」**全文都要掃，不是只掃官方資訊欄**——小編點評、比較表、內文、FAQ 一樣會出現（2026-09-24 被退：只清了官方資訊就說清完了）。只有這五類留出處：①價格欄位（官網價格）②「官網未標示／沒寫」的資料缺漏 ③使用禁忌與可否用在身上 ④效能與檢驗宣稱 ⑤查證出處（「查了十家官網」「以品牌官網為準」）（2026-09-24 使用者：「為何要一直強調官網」）。轉述不會把責任轉給品牌——文章是我們刊的。只有兩種情況要寫出處：①讀者該自己去查的（檢驗報告、法規審查狀態、成分來源）②使用禁忌（勿用於人體、不建議噴寵物身上、石材要稀釋）。其他地方直接寫事實
- [ ] 三大面向的 H3 是名詞堆（「領隊與緊急支援實務」），改完整句
- [ ] 破折號（—）一律不用，官方資訊、回購那種行最常夾帶
- [ ] 自己補的句子也要過：「先看比較表再往下讀」「本文以實務角度提供…」這種報幕句一樣是 AI 腔

- [ ] **前言 150 字以內**，人話優先。下面的範式是「要講到的事」不是句型：一句塞三個數字加括號、「這篇比了 N 家…各有一條對應的」「下面十個我照…排」這種公式收尾，使用者都說 AI 味（2026-09-14 post 326 被退兩次）。好的開頭是一個具體情境（「第一次去南投排行程，最常犯的錯是把清境和溪頭放在同一天」）：
  1. 先講這個市場的大架構：怎麼分區／分類、最常見的規格是什麼（新店：碧潭 vs 大坪林；澳洲團：三城 9 天 vs 兩城 9 天）
  2. 關鍵數字包 `<strong>`：價位帶、交通時間、容量規格這種可被 AI 直接抽走的事實，至少兩個
  3. 一句差在哪：價差來自什麼（飯店星級、購物站、外泌體來源）
  4. 收尾固定「這篇比了 N 家，A、B、C 各有一條對應的」，A／B／C 每一項都要是講完整的子句（「帶長輩出門要找台語導遊的」），不能是「帶長輩、單人報名、想省錢」這種兩三個字的殘句（2026-09-11 被點名 AI 味）
  不要寫成一句俏皮對比就結束，也不要有「本文以實務角度」「先看比較表」這種報幕
- [ ] **去 AI 味要拿 anti-ai-style.md 逐段判斷，不是跑正則**（2026-09-22 被點名「我是不是說你要用這個範本實際判斷過」）：把全篇散文段落攤出來，一段一段對 A～F 類；正則抓不到的：官網標語照抄（「一次到位」）、產品當主詞的假擬人（對付、拿、衝著、顧到、追不上、主攻、靠…去、處理）、「雷區」（踩雷家族，n8n 模板 2026-09-22 已改成「常見錯誤」）
- [ ] 取捨章與三大重點的 E-E-A-T（2026-09-22，785 是範本，被退過一次）：**不要整篇套第一人稱**，那讀起來像裝。只有真的有根據的地方才寫：研究資料裡真的看到「十家官網沒一家寫維持多久」就寫「查了十家官網，沒有一家寫…」；飼主真的問最多的（能不能直接噴寵物）就寫「飼主問最多的其實是…」；不編「朋友抱怨」「朋友問我」這種沒發生的事，不寫「我用過覺得」，不拿內部文件當來源。真正加分的是**機制**：氨偏鹼所以弱酸中和、季銨鹽只殺菌管不到空氣裡的味道、酵素要靜置、五種標章各是測什麼；講完機制接「所以怎麼做」。n8n `比較段落`、`前三章` 提示詞已同步
- [ ] **所有 h2／h3 逐一唸出聲**，照 `anti-ai-style.md` 第三節：要是一句主謂賓完整的短句。有冒號、兩個以上逗號、「問句？＋斷句」、結尾「不是…」的一律重寫（2026-09-14 post 326 的「日月潭、九族、埔里：一條路串起來，一天剛好」「住哪一區決定一天能玩幾個」被連退兩次）
- [ ] 小編點評不要「情境套句：規格、規格、規格」的冒號開頭（「帶小朋友放電的好去處：全票…」），第一句就講事實
- [ ] 網友正負評價是研究報告腔（「具娛樂性與知識性」「體驗被部分遊客認為不夠內場」「存在落差」），一條一條改成人話
- [ ] 小編點評：每則都是完整句，沒有殘句（「唱到半夜也不用管隔壁」→「唱歌唱到半夜也不怕被檢舉」）
- [ ] 小編點評沒有「品牌名＋以…為主軸」開頭、沒有「適合…的人」收尾、沒有 CP值／性價比／舒適／有質感／溫馨／貼心
- [ ] 沒有 B2B 模板殘留：外包 vs 自辦那一整章、「合作體驗」「續約意願」這種措辭
- [ ] 沒有「未見／未發現／查無…獲獎／認證／紀錄」這種沒資訊量的句子
- [ ] 沒有關鍵字硬塞（「適合碧潭住宿」「新店住宿與新北新店飯店推薦可依使用場景取捨」這種）
- [ ] 沒有負面新聞或內部研究備註被寫進去（命案報導、行政爭議、「房間數描述不一致」）

## 品牌數：預設 10 家（2026-09-11 定案）

生成器第一階段預設吐 8 家＋3 家備選，**不要照 8 寫**。第一階段清單出來先補到 10：備選裡挑同市場的，不夠就自己查（要有具體商品頁、確認真的有該品項、不是進口牌）。市面上真的湊不到 10 家夠格的（新店飯店那種小區域）才退，交件時講一句為什麼。標題的「精選 N 家」跟實際數量走。

## 品牌網址填專頁，不要填首頁（第一階段）

2026-09-16 隆鼻篇十家都填首頁，UI 警告「這是首頁，抓不到單一產品的規格與圖片」我按了照跑，結果卡片圖抓到 logo 陰影、研究抓不到價格，校稿時又只換了三家的連結成隆鼻頁，另外七家還是首頁，交件被問「為何有分歧」。**第一階段每一家都找到那個品項的專頁再填**（診所的隆鼻頁、飯店的房型頁、商品的產品頁），找不到才退回首頁，而且十家要一致。卡片下的連結說明會依網址深度自動變成「官方產品頁」。

## 推薦對象怎麼選（第一階段就決定，選錯要重跑）

判準不是字面上的商品 vs 服務，而是**品牌卡片需不需要圖**：

| 主題 | 選 |
|---|---|
| 飯店、餐廳、景點、實體店家、商品 | **產品** |
| 代操、顧問、教學、線上服務 | 服務／公司 |

選「服務／公司」的話 n8n 完全不抓圖，八張卡片會全部沒圖；比較段落也會套「外包 vs 自辦」的框架。

事後補救不用整篇重跑：去各家官網房型頁撈圖 → 裁 2:1／1200×600／JPEG q82 → 上傳 WP media（**要用 curl，python urllib 上傳會 403**）→ 補 alt → 把 `<div class="card-header-plain">…</div>` 換成 `<div class="card-hero"><img …><div class="hero-tag">…</div></div>`。
