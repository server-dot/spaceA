## 1. 比較表與價格（健檢重點，不進 n8n）

- [ ] **收費模式不能一整排「需聯絡公司洽詢」**。價格通常查得到，只是研究階段只讀首頁：
  - 房型子頁：`/room/content/<id>`、`rooms.php`、`?page_id=<id>` 常直接寫「定價 NT$…」
  - 官網外掛的訂房系統是另一個網域，但價格多半是純 HTML 抓得到（白金花園在 `booking.taiwantravelmap.com/user/booking.aspx?m=1024`）
  - 真的查不到才寫「官網未公開定價，需詢價」，不要寫「需聯絡公司洽詢」
- [ ] **必含品牌（客戶）一定要有價格**
- [ ] 表格欄位有沒有整欄破折號（代表那個欄位只有一家有資料，該欄不該存在）
- [ ] 產品／服務名稱欄不是整段描述

## 2. 內容與文案

先跑去 AI 味判讀（**每篇必跑，不是選配**）：把 `content.raw` 存成 `.html` 丟進一個資料夾，`cd /Users/kc/Desktop/qkangber && node scripts/check-ai-style.mjs <資料夾>`，腳本會把全文切段列出來，對照 `/Users/kc/Desktop/qkangber/docs/anti-ai-style.md` 逐段語意判讀（不是關鍵字比對），命中就重寫。推薦文常中的：

- [ ] 第一章「成效與成本差異／時間與上手難度／如何決定」＝ B2B 外包框架換皮，H3 全是冷標籤，整章重寫成這個主題自己的取捨（例：跟團還是自由行？先看你有幾天）
- [ ] 卡片的「實際使用感受」「回購傾向」兩行是研究備註口吻，「回購傾向」就是 B2B「續約意願」的變體，整行拿掉
- [ ] 三大面向的 H3 是名詞堆（「領隊與緊急支援實務」），改完整句
- [ ] 破折號（—）一律不用，官方資訊、回購那種行最常夾帶
- [ ] 自己補的句子也要過：「先看比較表再往下讀」「本文以實務角度提供…」這種報幕句一樣是 AI 腔

- [ ] **前言 150 字以內，照固定範式寫**（post 224、214 是範本）：
  1. 先講這個市場的大架構：怎麼分區／分類、最常見的規格是什麼（新店：碧潭 vs 大坪林；澳洲團：三城 9 天 vs 兩城 9 天）
  2. 關鍵數字包 `<strong>`：價位帶、交通時間、容量規格這種可被 AI 直接抽走的事實，至少兩個
  3. 一句差在哪：價差來自什麼（飯店星級、購物站、外泌體來源）
  4. 收尾固定「這篇比了 N 家，A、B、C 各有一條對應的」，A／B／C 每一項都要是講完整的子句（「帶長輩出門要找台語導遊的」），不能是「帶長輩、單人報名、想省錢」這種兩三個字的殘句（2026-09-11 被點名 AI 味）
  不要寫成一句俏皮對比就結束，也不要有「本文以實務角度」「先看比較表」這種報幕
- [ ] 小編點評：每則都是完整句，沒有殘句（「唱到半夜也不用管隔壁」→「唱歌唱到半夜也不怕被檢舉」）
- [ ] 小編點評沒有「品牌名＋以…為主軸」開頭、沒有「適合…的人」收尾、沒有 CP值／性價比／舒適／有質感／溫馨／貼心
- [ ] 沒有 B2B 模板殘留：外包 vs 自辦那一整章、「合作體驗」「續約意願」這種措辭
- [ ] 沒有「未見／未發現／查無…獲獎／認證／紀錄」這種沒資訊量的句子
- [ ] 沒有關鍵字硬塞（「適合碧潭住宿」「新店住宿與新北新店飯店推薦可依使用場景取捨」這種）
- [ ] 沒有負面新聞或內部研究備註被寫進去（命案報導、行政爭議、「房間數描述不一致」）
- [ ] 錨文字有資訊（不要「了解更多」），外連補 `target="_blank" rel="noopener"`
- [ ] 數字與邏輯對得上（「步行到捷運 30 分鐘算方便」這種要抓出來）
- [ ] FAQ 答案不是「適合…也適合…同樣合適」的空話

## 2b. 參考資料（每篇必檢）

n8n 的「參考內容」是 WF2 搜關鍵字拿到的 5 條結果，只有兩三句摘要、多半跟主題無關（澳洲一日遊那篇抓到澳洲旅遊局的隱私政策、外交部駐館資訊），內文其實沒參考到，卻被列成引用，讀者點進去反而扣分。真正撐內文的是研究階段的 brandDetails（各家官網行程頁＋Dcard／PTT／TripAdvisor 討論串）。

- [ ] 把 n8n 生的 5 條逐一點開，跟主題無關的（隱私政策、法規全文、駐館資訊、學位論文）拿掉；跟主題有關的官方來源留著（例：食藥署外泌體化粧品審查公告、新北合法旅館名冊、澳洲旅遊局一日遊介紹）
- [ ] 補上研究階段真的讀過的社群來源：從 n8n execution 的 `注入參考內容` 節點拿 `brandDetails[].reference_links`（Dcard／PTT／TripAdvisor／部落格），每家挑 1～2 條，標題寫「來源：主題」（例「PTT Hotel 板：帝景飯店住宿心得」）
- [ ] **官方行程頁／產品頁不列**，卡片下面已經有「官方網站」連結，再列是重複
- [ ] 8～10 條以內，全部要能點開；沒有參考資料區塊的舊文章（187 那種）補一段 `<h2>參考資料</h2><div class="article-references">`

## 推薦對象怎麼選（第一階段就決定，選錯要重跑）

判準不是字面上的商品 vs 服務，而是**品牌卡片需不需要圖**：

| 主題 | 選 |
|---|---|
| 飯店、餐廳、景點、實體店家、商品 | **產品** |
| 代操、顧問、教學、線上服務 | 服務／公司 |

選「服務／公司」的話 n8n 完全不抓圖，八張卡片會全部沒圖；比較段落也會套「外包 vs 自辦」的框架。

事後補救不用整篇重跑：去各家官網房型頁撈圖 → 裁 2:1／1200×600／JPEG q82 → 上傳 WP media（**要用 curl，python urllib 上傳會 403**）→ 補 alt → 把 `<div class="card-header-plain">…</div>` 換成 `<div class="card-hero"><img …><div class="hero-tag">…</div></div>`。
