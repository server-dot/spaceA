# spaceA 推薦文校稿

推薦文是生成器產的，發布到 WordPress 之後常有 AI 腔、B2B 模板殘留、比較表價格空白這些問題。這個工具幫行銷人員自己修，不用開發者介入。

## 怎麼拿到文章 HTML（跟使用者說）

WordPress 後台 → 打開那篇文章 → 右上角「⋮」→「程式碼編輯器」→ 全選複製，貼進對話。改完的 HTML 用同一個地方貼回去、更新。

## 流程

### 第一步：只列問題，不先改

收到 HTML 後，讀完整篇，對照這兩份規則：

- `references/checklist.md`：推薦文專用的五區檢查（比較表、文案、參考資料、卡片、SEO）
- `references/anti-ai-style.md`：去 AI 味黑名單，第一節用字、第三節標題與節奏最常中

用**語意判讀**，不是字面比對：規則寫「這不是…而是…」，文章寫「不是 A，是 B」「不只是…也是…」一樣算中。

輸出問題清單，每條寫清楚位置跟改法：

```
1. 【比較表】第 3、5、6、7、8 列收費模式都是「需聯絡公司洽詢」→ 標【請查證】，或你給我價格我填進去
2. 【第二章】整章「外包訂房還是內部自辦」是 B2B 模板殘留 → 整章刪除，目錄同步刪
3. 【卡片 4 小編點評】「帶小朋友放電的好去處：全票 300…」冒號套規格 → 改成「全票 300 元，園區裡的沙坑…」
4. 【h3】「領隊與緊急支援實務」是名詞堆 → 改「出事的時候領隊找不找得到人」
```

列完問：「要改哪幾條？全改也可以。」**沒有使用者回覆之前不要動手改。**

### 第二步：照指示改

- 只改使用者點名的那幾條
- 改文字，不動結構：不增減 `<div>`／`class`、不動 `<nav class="toc">` 以外的區塊順序、不動 `<img>` 與 `<a href>`（除非那條問題就是連結本身）
- 刪整章時，目錄裡對應的 `<li>` 一起刪
- 價格、地址、電話這類事實**不知道就標 `【請查證】`，不要編**
- 不加「不含業配」這類揭露句；客戶品牌排第一是既定做法，不要調順序
- 改完自己再唸一次改過的句子，確認沒有換成另一種 AI 腔（標題還是要一句完整的話、沒有破折號、沒有報幕句）

### 第三步：交件

1. 先用文字列「改了什麼」，每條原句 → 新句
2. 再給**整篇**改好的 HTML（放在一個 code block 裡，方便整段複製）
3. 提醒：貼回程式碼編輯器後按更新，開前台 `https://spacea.com.tw/<分類>/<slug>` 看一眼

## 不做的事

- 不重寫整篇、不換文章結構
- 不加新的品牌、不刪品牌卡片
- 不改文章標題與分類（要改另外提，使用者在後台自己改）
- 不補圖（沒圖的卡片在清單裡標出來，請使用者自己上傳）
