# 推薦文校稿清單

生成器吐出來的推薦文常見的毛病，照這五區逐項看。每一條都附「原句 → 改法」，判斷時對照實例，不要只比對字面。

---

## 1. 比較表與價格

- **收費模式不能一整排「需聯絡公司洽詢」**。飯店房價、商品價格多半查得到，生成器只是沒去找。
  - ❌「需聯絡公司洽詢」×5 列
  - ⭕「雅緻雙人房含早餐 NT$3,600 起」；真的查不到才寫「官網未公開定價，需詢價」
  - 校稿時查不到價格就在那格標 `【請查證：官網房型頁或訂房系統】`，不要編一個數字
- **客戶（必含品牌）那一列一定要有價格**，不能是「需詢價」
- 整欄都是破折號的欄位代表只有一家有資料，整欄刪掉
- 「產品／服務名稱」欄要是名稱，不是一段描述
- 數字跟邏輯要對得上：「步行到捷運 30 分鐘算方便」這種要抓出來

## 2. 內容與文案

### B2B 模板殘留（生成器原本是寫「找代操公司」用的）
- 整章 `<h2>外包訂房還是內部自辦？</h2>`（或「外包 vs 自辦」「成效與成本差異／時間與上手難度／如何決定」三個 H3）套在飯店、商品、景點上完全不通 → **整章刪掉**，目錄 `nav.toc` 對應的那個 `<li>` 也刪
- 品牌卡片末尾「合作體驗：」「續約意願：」「回購傾向：」「實際使用感受：」這幾行是研究備註口吻 → 整行刪掉；真的有內容才改成消費者語氣（「入住體驗：」「回訪意願：」）

### AI 腔的免責句
- ❌「資料不足時我會誠實說明並給出可執行的建議。」
- ❌「看不出好壞就老實說看不出來。」
- ❌「每一條的團費都是從行程頁直接抄下來的」「以上資料皆經查證」
- ❌「先看比較表再往下讀」「本文以實務角度提供…」
- → 這類自我背書、報幕句**整句刪掉**，後面內容不動

### 前言（150 字以內）
- 開頭是一個具體情境，不是一句俏皮對比
  - ❌「新店飯店怎麼選？答案比你想的簡單。」
  - ⭕「第一次去南投排行程，最常犯的錯是把清境和溪頭放在同一天。」
- 要講到：這個市場怎麼分區／分類、價位帶（至少兩個具體數字包 `<strong>`）、價差來自什麼
- 收尾「這篇比了 N 家，A、B、C 各有一條對應的」，A／B／C 要是完整子句
  - ❌「帶長輩、單人報名、想省錢」
  - ⭕「帶長輩出門要找台語導遊的」

### 標題（h2／h3 逐一唸出聲）
要是一句主謂賓完整的短句。有冒號、兩個以上逗號、「問句？＋斷句」、結尾「不是…」的一律重寫。
- ❌「日月潭、九族、埔里：一條路串起來，一天剛好」→ ⭕「日月潭、九族、埔里一天可以排在一起」
- ❌「住哪一區決定一天能玩幾個」→ ⭕「住宿選在埔里，隔天去哪裡都順路」
- ❌「領隊與緊急支援實務」（名詞堆）→ ⭕「出事的時候領隊找不找得到人」
- ❌「穩定器和三腳架怎麼挑，不是兩個都要買」→ ⭕「穩定器和三腳架先挑一個就好」

### 小編點評（每張卡都有）
- 每則都是完整句，第一句就講事實
  - ❌「帶小朋友放電的好去處：全票 300、有沙坑、有滑梯」（冒號套規格）
  - ⭕「全票 300 元，園區裡的沙坑和滑梯能讓小朋友耗掉一個下午。」
  - ❌「唱到半夜也不用管隔壁」（殘句）→ ⭕「唱歌唱到半夜也不怕被檢舉」
- 不要「品牌名＋以…為主軸」開頭、不要「適合…的人」收尾
- 禁用詞：CP值、性價比、舒適、有質感、溫馨、貼心

### 網友評價
- 研究報告腔改成人話
  - ❌「具娛樂性與知識性」「體驗被部分遊客認為不夠內場」「存在落差」
  - ⭕「網友說解說員講得比想像中有趣」「有人抱怨只能在外圍看，進不了工廠」

### 其他要刪要改的
- 「未見／未發現／查無…獲獎／認證／紀錄」這種沒資訊量的句子 → 刪
- 負面新聞、內部研究備註（命案報導、行政爭議、「房間數描述不一致」）→ 刪
- 關鍵字硬塞（「適合碧潭住宿」「新店住宿與新北新店飯店推薦可依使用場景取捨」）→ 改成自然句或刪
- 破折號（—）一律不用，改括號或句號
- `<strong>` 要包判斷句，不能只包關鍵字或價格
  - ❌`<strong>新店飯店</strong>房價 <strong>NT$1,200 到 3,500</strong>`
  - ⭕`<strong>新店飯店的房價多在 NT$1,200 到 3,500，碧潭湖景房會比大坪林貴一截</strong>`
- 錨文字要有資訊（不要「了解更多」「點此」），外連補 `target="_blank" rel="noopener"`
- FAQ 答案不是「適合…也適合…同樣合適」的空話，每題給一個明確判斷
- 揭露句：客戶排第一是既定做法，**不要加「不含業配」**這種句子

## 3. 參考資料區塊

- 生成器列的 5 條多半跟主題無關（隱私政策、法規全文、駐館資訊、學位論文）→ 拿掉
- 跟主題有關的官方來源留（食藥署公告、合法旅館名冊、觀光局介紹）
- 官方產品頁不列（卡片下面已有「官方網站」連結）
- 全部要能點開，8～10 條以內

## 4. 品牌卡片

- 每張卡都要有圖；沒圖的標出來請使用者補（生成器抓的是 og:image，常是海報、logo、色塊）
- 官方資訊是條列、地址可點開地圖、官網／電話有連結
- 連到首頁寫「官方網站」，連到某一款商品才寫「官方產品頁」
- `href` 沒有夾到換行或第二個網址

## 5. 標題與 SEO

- 文章標題：句型輪著用、年份留一半，不要每篇都「OO怎麼選？2026 精選 N 家」
- 「精選 N 家」的 N 跟實際卡片數量一致
- 分類不是「未分類」（未分類的文章前台不會顯示）
